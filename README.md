# 일행 드라이브 (Ieum Drive)

여러 대의 차가 함께 이동할 때 쓰는 차량용 앱입니다. 내비 옆 화면에서 일행 차의 위치와 거리를 보고, "휴게소에서 쉬어요" 같은 메시지를 원탭으로 보내면 다른 차에서 음성으로 읽어 줍니다. 집결지나 목적지를 공유해 내비 경유지로 바로 넣을 수 있습니다.

현대자동차그룹 차량용 앱 개발 공모전(Pleos) 출품작입니다.

## 플랫폼
- Pleos Connect (Android Automotive 기반), Android API 28 이상, Kotlin
- Pleos SDK: NaviHelper, Vehicle

## 실행 방법
준비 중입니다.

## 테스트 환경
- Pleos Connect 에뮬레이터 (API 34, Pleos Connect v2.1.0)
